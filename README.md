# Telegram-бот для регистрации заказов

Бот собирает заказы в Excel-файл `orders.xlsx`. Продавцы могут добавлять записи; команды просмотра и выгрузки доступны только Telegram ID администратора.

## Поля заказа

- Дата заказа (сегодня подставляется автоматически, можно изменить)
- Номер торговой точки
- Адрес торговой точки
- Серийный номер SIM-карты
- Номер SIM-карты
- Сумма заказа
- Сотрудник, который продал

Также автоматически сохраняются ID записи, Telegram ID того, кто внёс заказ, и дата/время внесения.

## 1. Создайте бота в Telegram

1. Откройте Telegram и найдите `@BotFather`.
2. Отправьте `/newbot`.
3. Укажите имя и username бота.
4. Скопируйте токен. Не публикуйте его и никому не пересылайте.

## 2. Узнайте свой Telegram ID

Напишите `@userinfobot` или воспользуйтесь другим проверенным ботом для определения собственного числового Telegram ID. Укажите его в `.env` как `ADMIN_ID`.

## 3. Установите Python

Установите Python 3.11 или новее с официального сайта https://www.python.org/downloads/.
Во время установки Windows отметьте пункт **Add Python to PATH**.

## 4. Настройте проект

Распакуйте архив в отдельную папку.

В терминале/командной строке перейдите в папку проекта и выполните:

```bash
python -m venv .venv
```

Активация виртуального окружения:

**Windows**
```bash
.venv\Scripts\activate
```

**macOS / Linux**
```bash
source .venv/bin/activate
```

Установите библиотеки:

```bash
python -m pip install -r requirements.txt
```

Скопируйте `.env.example` в файл с именем `.env` и заполните `BOT_TOKEN` и `ADMIN_ID`.

**Windows (Командная строка):**
```bat
copy .env.example .env
```

**macOS / Linux:**
```bash
cp .env.example .env
```

Откройте `.env` в текстовом редакторе и замените значения на свои. Не добавляйте кавычки вокруг токена. Не отправляйте файл `.env` другим людям.

## 5. Запустите бота

```bash
python bot.py
```

Пока программа работает, бот отвечает в Telegram. Чтобы остановить, нажмите `Ctrl+C` в терминале.

## Команды

- `/start` — открыть меню
- `/new` — добавить заказ
- `/cancel` — отменить заполнение
- `/export` — отправить администратору Excel-файл
- `/orders` — показать администратору последние 10 заказов

У продавца нет команды просмотра или выгрузки заказов. После сохранения администратор получает уведомление о новом заказе.

## Ограничение доступа продавцов

По умолчанию любой пользователь, который откроет личный чат с ботом, может добавить заказ, но не может просматривать все заказы. Чтобы разрешить внесение заказов только определённым продавцам, заполните `ALLOWED_SELLER_IDS` в `.env` списком Telegram ID через запятую, например:

```env
ALLOWED_SELLER_IDS=111111111,222222222,333333333
```

Администратор всегда сохраняет доступ к внесению заказов и административным командам.

## Важные замечания

- Файл `orders.xlsx` хранится на компьютере/сервере, где запущен бот. Для постоянной работы бот должен быть запущен постоянно.
- Не открывайте `orders.xlsx` в Excel одновременно с записью новых заказов: файл может быть заблокирован. Закройте Excel перед внесением новых записей.
- Сделайте резервные копии `orders.xlsx`.
- В файле будут номера SIM-карт и серийные номера — ограничьте доступ к папке проекта и файлу.
- Для круглосуточной работы перенесите проект на VPS/сервер и настройте автоматический запуск.
- Если несколько продавцов вносят записи одновременно, для небольшой команды это обычно подходит, но для интенсивной параллельной работы лучше перейти на базу данных с последующей выгрузкой в Excel.
